What this website collects

The AVIO website is a static informational site. We have not configured analytics, advertising trackers, user accounts, or a contact-form backend. The contact form prepares text locally and may copy it to your device clipboard after you choose to submit; the website does not transmit that message to AVIO.

Third-party services

The site uses Google Fonts, which may receive network requests and technical information when fonts load. When the website is served via GitHub Pages, GitHub may process technical access logs according to its policies. Following a link to GitHub or submitting an issue means GitHub's own privacy terms apply.

External links

Our external GitHub link is github.com/panagiotagrosdouli/AVIO. We do not control the privacy practices of linked websites.

Contact

For privacy questions, start a conversation in the repository's GitHub Issues area. Avoid posting personal or confidential details publicly.
