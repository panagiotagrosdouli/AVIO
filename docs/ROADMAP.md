# AVIO Engineering Milestones

| Phase | Scope | Exit evidence |
|---|---|---|
| 1A | Three-agent deterministic mission, dashboard, report, tests | Nine unique targets covered, tests pass, source-labeled synthetic evidence |
| 1B | PX4 SITL + Gazebo + ROS 2 multi-vehicle integration | Three distinct flight stack instances, namespaces, log recordings and CI smoke tests |
| 2 | Navigation, obstacle scenes, geofence, recovery | Quantified clearance, successful completion and abort/recovery scenarios |
| 3 | Sensor perception and infrastructure inspection | Held-out defect data, precision/recall, uncertainty analysis |
| 4 | Cooperative mapping and coordination | Independent-agent baseline comparisons for ATE/RMSE, bandwidth, map consistency and time |
| 5 | Hardware safety and compliance readiness | Safety case, operator procedures, regulatory and real-world validation gates |

Track mission completion, coverage, minimum separation, logged safety incidents, false positives, localization error, inter-UAV bandwidth and provenance completeness.

Phase 1A is a **non-physics software-only demo**, not a validated product. The later milestones are plans, not current capabilities.
