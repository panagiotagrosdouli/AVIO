Accessibility

AVIO aims to make its website usable across devices, input methods, and assistive technologies.

Current features

  • Responsive layouts for smaller screens
  • Keyboard-operable navigation and form elements
  • Visible focus indicators and labeled form fields
  • Reduced-motion support
  • Semantic headings, text alternatives, and structured content

Limitations

We have not completed a formal WCAG conformance audit. If you encounter an access barrier, please create an issue in the project repository describing the page and issue.
