# AVIO — three-UAV motion-evidence gate

The movement gate checks **independent local-position variation**, not physical flight. It cannot prove the input was generated by PX4 SITL, that a model exists in Gazebo, that the aircraft actually moved, that frames are globally aligned, or that vehicles remained safely separated.

## Input

The read-only ROS 2 observer produces JSONL samples from `VehicleLocalPosition`, with vehicle ID `uav_1..uav_3`, PX4 timestamp, UTC received-at timestamp, provenance tag, and converted per-vehicle local ENU XYZ coordinates. The source tag is not authenticated.

## Run on a captured session

```bash
python3 -m unittest discover -s tests -v
python3 -m integrations.ros2.telemetry_quality \
  artifacts/sitl/session/telemetry.jsonl --minimum-samples 10
python3 -m integrations.ros2.motion_evidence \
  artifacts/sitl/session/telemetry.jsonl \
  --minimum-samples 10 \
  --minimum-displacement-m 0.5 \
  --minimum-path-m 0.5 \
  --jitter-deadband-m 0.03 \
  --out artifacts/sitl/motion-evidence.json
```

For a session that was explicitly designed to move all three vehicles, the existing evidence gate can additionally require local-motion evidence:

```bash
python3 -m integrations.ros2.evidence_gate \
  artifacts/sitl/session/manifest.json \
  --minimum-samples 10 --require-motion
```

Do not use `--require-motion` for a stationary hover or preflight-only session. It is an opt-in trial requirement, not a general safety criterion.

These defaults are **illustrative thresholds**, not scientifically validated flight-performance acceptance criteria. Collect a stationary baseline to quantify estimator jitter and select displacement and deadband thresholds based on actual noise and task geometry. A stationary vehicle can be a correct result for a hover test, so the requirement that all three move applies only to the specific movement trial.

The audit checks that each local track contains a sufficient number of records, covers a minimum reception-time span, has no excessive reception gaps, and has finite coordinates. It reports net first-to-last displacement and cumulative sampled step length excluding movements below the deadband. The measurements can include estimator drift; they are not independent ground truth.

## Full SITL acceptance is separate

Run and document three distinct PX4 instances and Gazebo models, actual topic messages and ROS bag contents, model movement observed independently, version-pinned toolchain, clock/frame alignment and hazard/failsafe tests. **No autonomous command interface is introduced by this gate.**

Official reference: https://docs.px4.io/main/en/ros2/multi_vehicle
